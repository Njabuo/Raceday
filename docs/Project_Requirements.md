# RaceDay Part 1 Requirements

## Functional Requirements

The RaceDay system should support:

- User registration and login.
- Organiser profile management.
- Participant profile management.
- Event creation and management.
- Race category management.
- Participant enrolments.
- Recording and viewing race results.

## User Roles

### Organiser

Organisers can:

- Create and manage events.
- Create and manage race categories.
- View event enrolments.
- Record race results.

### Participant

Participants can:

- Manage their profile.
- View available events and categories.
- Enrol in race categories.
- View their own enrolments.

## Public Access

Unauthenticated users can view available events, categories and published race results.
